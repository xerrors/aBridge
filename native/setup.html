安装与修复 aBridge

运行时与 Cua Driver

在“设置 → 运行环境”点击“安装 / 修复”。这会使用锁定依赖和哈希校验修复当前用户的 Python 环境，不需要另装 Cua App 或本地模型。

若提示缺少 uv，先按uv 安装说明安装，再重开 aBridge。若安装文件不完整，在内部项目源目录运行：

python3 deploy/install_client.py
open "$HOME/Applications/aBridge.app"

系统权限

分别点击“屏幕录制”和“辅助功能”旁的“前往设置”，允许实际安装的 aBridge。原生更新后，macOS 可能要求重新允许；按系统提示退出并重开客户端。

浏览器

安装Google Chrome。启用本机“浏览器”能力，并在管理台明确给 Agent 增加浏览器授权。

任务使用系统 Chrome 的专用临时窗口；结束会话时清理窗口和临时 profile。个人 Chrome 标签页与登录态不参与这条连接。

连接与诊断

已有绑定时留空设备 Key，点击“重试连接”。“重新检查”更新运行环境状态；“查看诊断”打开仅保存在本机的错误日志。

日志、版本、安装、权限和服务连接是不同状态。缺失的能力不会作为可用能力上报。
