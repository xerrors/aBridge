# Windows 客户端界面

Windows 客户端用 Rust 调用 Win32 控件、系统托盘和桌面活动边框。主窗口显示设备、连接状态、暂停和停止按钮以及四项本机能力。服务器绑定和运行诊断可以按需展开。关闭窗口后客户端留在托盘，从托盘退出时会等待设备进程结束。

## 参考

- [Flow Launcher](https://github.com/Flow-Launcher/Flow.Launcher)：参考轻量常驻 Windows 工具的原生窗口和托盘交互。
- [Microsoft PowerToys](https://github.com/microsoft/PowerToys)：参考系统工具的设置分组与清晰状态呈现。

主操作和在线状态使用 aBridge 的品牌蓝。外观可以跟随系统，也可以固定为浅色或深色。

## 状态与交互

- 在线待命、正在执行、已暂停、连接中断、尚未绑定与状态待确认分别呈现；读取失败不能保留在线假象。
- 设备绑定与服务器地址在已绑定时只读。重连保留设备身份和暂停状态，解绑需要明确确认。
- 能力开关反映本机请求，实际不可用的能力由诊断说明；开关请求失败刷新真实状态。
- 浏览器授权、取消授权与可选手动 Device Key 绑定经私有管道交给 Rust 内核；未加密 HTTP 地址需要本机明确确认。
- `Ctrl+Alt+Shift+P` 与托盘菜单提供暂停。桌面操作时显示品牌蓝细流光边框，支持多显示器、点击穿透与减少动态效果；空闲不播放动画。
- 同一状态目录只运行一个原生壳。重复启动激活现有窗口，不创建第二个设备运行时。

本机窗口和指示器只负责呈现及系统交互；授权、会话、去重、观察引用、接管检测和执行逻辑由独立 Rust 内核负责，沿用共享协议、原状态格式与 PowerShell 驱动行为。

设置界面采用系统按钮、编辑框、复选框、下拉框和折叠分组，通过间距、层级、圆角主按钮及明暗配色呈现；分组顺序、中文文案、默认展开状态及操作逻辑沿用 PR #22 的 `7dff8b4`。连接分组在未绑定时展开，Device Token 默认折叠且输入掩码；本机能力默认展开，偏好和诊断默认折叠。控件保留系统键盘导航与可访问名称，深浅主题切换复用原偏好格式。状态未变化时不重复更新控件或布局；新错误自动进入可见区域。
