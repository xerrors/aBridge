# 架构与模块职责

当前是一个服务进程和一个 macOS 设备客户端。服务提供管理 API、MCP 与设备 WebSocket；客户端主动出站连接，不开放本机入站执行端口。

```text
Yuxi / MCP 客户端 ─ Agent Key ─ /mcp ─┐
管理台 ─ 管理登录会话 ─ /api ─────────┤ aBridge 服务
                                     │ SQLite + 在线设备路由
                                     └─ 设备 WebSocket ─ Mac 客户端
                                                        ├ 截图 / 键鼠
                                                        ├ Shell
                                                        └ 文件
```

## 服务端

| 模块 | 职责 |
| --- | --- |
| `server.py` | HTTP 入口、管理会话、设备连接认证和连接生命周期 |
| `mcp_gateway.py` | 官方 MCP SDK 工具声明、Agent 认证和结果编码 |
| `runtime.py` | 权限交集、会话租约、设备路由、去重、取消和结果状态 |
| `storage.py` | SQLite 身份、授权、会话与操作元信息 |
| `static/` | 无前端构建依赖的管理台与品牌矢量资产 |

管理登录、设备 Key 与 Agent Key 不可互换。主体与设备归属从认证和持久关系取得，不接受模型自报身份。每次执行重新检查授权、设备、会话、能力和当前连接代次。

SQLite 和在线设备连接由同一服务进程持有，仅支持一个 worker。存储不交给并发线程复用；异步业务边界保持明确。没有队列重放：服务重启时未完成操作标记为结果未知。

## 设备端

| 模块 | 职责 |
| --- | --- |
| `client.py` | 出站连接、心跳、本机控制、能力上报和持久操作去重 |
| `executor.py` | 当前用户级 Shell、UTF-8 文件和原生助手调用 |
| `native/aBridge.swift` | 菜单栏 UI、App 权限、Keychain、屏幕捕获与输入 |
| `native/build.py` | 可复现构建输入、版本、签名校验和原生构建缓存 |
| `deploy/` | 明确调用的源码安装及可选内网转发工具 |

当前执行能力只有 `screen`、`input`、`shell`、`files`，不是 Cua 或浏览器驱动适配层。新增能力必须同时完成服务授权、设备实现、本机开关和验证，不能先暴露占位。

本机有效能力是配置开关与实际权限的交集；服务再与设备授权和 Agent 授权取交集。前台输入会话独占。暂停持久保存，只有本机恢复操作能解除；断线、过期、撤销和停止均沿现有取消路径处理。

## 执行与结果

操作用稳定 `operation_id` 去重。同 ID 改参数拒绝，结果未知时不自动换 ID 重试。服务只短暂保留结果内容，SQLite 不保存命令、输入、文件正文或截图。

桌面观察返回主屏 PNG、坐标换算信息和窗口元数据。输入引用本连接 10 秒内的观察，并复核前台 PID/标题；当前没有 AX 控件树、元素级动作或窗口/显示器选择工具。

`executed` 表示执行器回执，不能代替业务结果验证。Shell、文件和输入均使用当前系统用户权限，不构成沙盒。

## 版本与演进

`abridge/__init__.py` 是版本唯一来源。模块不为形式上的分层继续拆分；新增抽象应表达稳定领域职责。

Cua 内嵌 SDK、浏览器 DOM、依赖诊断和安装引导按 [后续计划](roadmap.md) 推进。原型中的候选架构与演示界面不是已实现系统。设计约定与资产入口见 [设计说明](design.md)。
