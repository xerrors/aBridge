# 变更记录

此文件记录产品行为变更；部署日志、私人任务结果与模型验收流水不作为版本记录。

## 0.4.19 — 正式发布（2026-11-19）

- 浏览器观察改进文本与表格的分页和来源校验。原生输入改进滚动后的定位、点击结果核验与导航恢复，扩展使用新增的 `webNavigation` 权限识别任务页打开的新标签。
- macOS 支持通过本地化名称查找运行中的 App，刷新 PID 时保留已选窗口，并在原生会话过期后恢复观察。点击前核对窗口、弹出菜单和目标，取消读取时保留已确认的动作回执。
- 新增 aBridge 官网、运行机制说明与公开评测。新增 Android 客户端预览，提供屏幕、输入和文件能力，安装包独立构建。

## 0.4.18 — 正式发布（2026-11-18）

- 新增 Linux 命令行客户端，提供 amd64 和 arm64 安装包。可用 Device Token 绑定主机，向 Agent 授予 Shell 和文件能力，并通过用户级 systemd 服务在后台运行。
- 管理台可查看设备上报的系统与账户详情。开发数据库升至 schema 6；使用旧开发数据库的部署应先备份，在副本中转换或重新初始化。
- macOS 点击操作绑定到此前观察的窗口，减少目标窗口变化导致的误点；修复 macOS 15 上的构建兼容问题。
- 浏览器扩展改进控件识别、原生输入和无效选项处理。固定模型、种子和预算的 MiniWoB++ 适配子集，严格成功数从 5/12 提升至 12/12。[评测条件与结果](benchmarks/browser-reliability-v2.md)

## 0.4.17 — 正式发布（2026-11-17）

- 修复 0.4.16 原生 macOS 客户端无法连接 Server 的问题。设备消息改用服务端要求的 JSON 文本帧。
- 从 0.4.16 可直接应用内更新。从 0.4.15 或更早版本升级时，退出旧 App，解压新版 ZIP 并替换原位置的 `aBridge.app`；保留应用数据目录即可沿用设备身份、绑定与暂停设置。

## 0.4.16 — 预发布（2026-11-17）

- macOS 客户端和更新器迁至 Swift，桌面操作直接调用 Cua 原生库。Apple Silicon 应用包移除了内置 Node.js 运行时，继续支持 Shell、文件和已有设备授权。
- **已知问题**：此版原生客户端发送的 WebSocket 帧类型与 Server 不匹配，导致 Mac 无法建立设备连接。Chrome 扩展和 Server 不受影响，Mac 用户请使用 0.4.17 或更高版本。

## 0.4.15 — 正式发布（2026-11-17）

- 修复浏览器扩展的定时器调用，恢复设备连接、心跳和自动重连。扩展上报浏览器声明的品牌，升级并重连一次后，管理台在设备离线或 Server 重启后也能显示对应名称与图标。
- 管理台和扩展诊断页新增版本号，修复扩展弹窗滚动时的背景断层。macOS 权限设置新增可拖入系统设置的 App 图标和在 Finder 中定位的入口。

## 0.4.14 — 正式发布（2026-11-17）

- **协议变更**：管理接口改用 `/api/agent-connections` 和 `agent_connection_id`。MCP 客户端查询或取消操作时，应将服务端返回的 `operation_id` 传给 `operation_status` 或 `operation_cancel`；请求中自行指定的 ID 仅在原授权和会话内用于去重。
- 改进设备断连后的会话恢复、浏览器任务取消与资源清理。管理台新增设备平台和版本，操作记录显示短 ID。
- 开发数据库升至 schema 5。升级前备份旧库，在隔离副本中验证转换；此版未提供自动迁移。

## 0.4.13 — 正式发布（2026-11-17）

- 重构管理台布局与导航，按功能组织页面和样式，优化设备、连接及操作记录的展示。
- macOS App 补全编辑菜单与常用快捷键，优化原生菜单显示。
- 桌面整屏观察在焦点无法确认时仍可返回截图，同时禁用像素输入；仅指定 PID 时，单窗口自动选择，多窗口明确提示选择目标。
- Server 分发包携带完整生产依赖，不再依赖 npm shrinkwrap 命令，从根锁文件安装已测试的固定依赖，并核验打包后的依赖路径、版本及桌面依赖隔离。
- 文件工具拒绝可能阻塞执行的特殊文件；浏览器操作终止时保留步骤诊断，账户身份切换时重建管理视图。
- 增加基于 MiniWoB 自有任务的真实 Agent 基准工具与结果报告。

## 0.4.12 — 正式发布（2026-11-16）

- 浏览器批次失败保留子步骤状态、原始错误及恢复信息，区分明确拒绝、执行失败、取消和结果未知；已完成动作或导航的后观察失败不再覆盖执行回执。
- 任务页清理共享同一次结果，修复超时、取消、停止及旧任务迟到导致的清理竞态；清理失败保留记录，任务页缺失时明确提示重新打开。
- 浏览器观察的 `query` 支持字符串数组按任一子串匹配，正文与控件保持一致、去重并限制预算；链接增加声明的 `target`，工具说明明确固定当前任务页，不自动接管新标签。

## 0.4.11 — 正式发布（2026-11-16）

- Server 新增显式公网 HTTP 开关，允许保留 OIDC 单点登录与平台委托；默认仍要求 HTTPS。

- 修复 macOS 更新后正常运行仍被误回滚的问题；启动确认独立于设备连接状态，保留运行时启动失败时的回滚保护。

## 0.4.10 — 正式发布（2026-11-16）

- 非本机 HTTP 连接由明确确认弹窗替代硬拦截，确认绑定具体 Server Origin；两种授权方式共用现有设备身份和暂停/撤销机制。
- Token 绑定先验证有效性与设备类型，取消或验证失败保留原绑定，扩展换绑隔离旧连接的迟到事件。

## 0.3.0 — 开发候选（2026-11-13）

### 架构

- Server、桌面运行时、扩展与管理台统一为 strict TypeScript，共享 `abridge/1` 协议和消息 schema。
- Server 使用 Fastify 5、官方 MCP SDK v2 与 Node 内置 SQLite；管理台采用预构建 Preact 11 静态产物。
- CLI 默认启动 Server，提供 `--web` 管理台入口、数据目录及反向代理来源配置。
- Swift 壳调用独立 Node 运行时；桌面按需加载官方 Cua Node SDK，Server 分发剥离桌面依赖。
- 软件版本改由根 `package.json` 单源生成各分发产物版本。

### 执行

- App 与浏览器扩展分别注册设备并直接连接 Server，独立授权、暂停与清理任务资源。
- 浏览器导航固定返回新观察；动作默认附带后观察，观察失败与动作效果分别返回。
- Shell 默认最多等待 15 秒，短命令直接返回结果；长任务可继续等待、取消及按偏移分页读取。
- 区分闲置到期、停止、连接中断和服务重启，结果未知的动作不自动重放。
- Host/Origin 使用明确白名单；首次管理账户的浏览器配置仅限回环空数据库与一次性令牌。

本版本的构建、协议与打包检查不代表实际 App 系统权限、桌面输入或既有线上服务已完成替换验收。
