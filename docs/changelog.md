# 变更记录

此文件记录产品行为变更；部署日志、私人任务结果与模型验收流水不作为版本记录。

## 0.4.4 — 开发候选（2026-11-14）

- 修复管理台跨标签切换账户时身份与数据不一致，以及刷新失败后保留旧设备在线状态的问题。
- 修复桌面端异步能力预检阻塞取消、关闭会话和停止指令的竞态，取消后不再派发预检中的操作。
- MCP 对设备失败、拒绝及结果未知的操作标记工具错误，保留已执行动作的后观察失败语义。
- 更新外部身份建账和管理员链接说明，终端不输出管理员凭据。
- 平台连接首次建立和显式重新授权时默认访问本账户全部设备（含新设备），保留已有连接的自定义策略及撤销状态。
- 已撤销的当前平台连接直接显示在 Agent 连接列表，提供明确的重新授权确认；平台名称可通过 `ABRIDGE_OIDC_CLIENT_NAME` 配置。

## 0.4.3 — 开发候选（2026-11-14）

- 增加可选 OIDC 统一登录，以 issuer 和 sub 隔离外部身份；登录页和管理员账户登录弹窗均提供统一登录入口。
- 支持显式开启平台 MCP 委托，验证最长 60 秒的签名令牌；平台连接默认无设备权限，撤销后须显式重新授权并重新选择设备。
- 支持认证私网 backchannel 与 Server Docker 镜像构建；远程登录要求 HTTPS，终端不再输出管理员 Token。
- 固定新增认证依赖版本，使源码验证与分发包使用相同的直接依赖。
- App 首次绑定默认使用系统电脑名称，未绑定时也显示默认名称；浏览器可读取已获准的 Profile 账户作为默认名称，也可手动命名。
- 开发数据库 schema 升至 3，旧开发数据库需备份后明确转换或重新初始化。

## 0.4.2 — 开发候选（2026-11-14）

- 管理台设备能力改为只读展示，设备编辑接口仅允许修改名称；本机能力开关由客户端管理，Agent 连接策略继续独立配置。
- 管理台、浏览器扩展和 Mac App 支持编辑设备名称，服务端通过连接欢迎消息和心跳确认同步名称，兼容既有 120 字符设备名。
- 设备详情重排名称、状态、类型、平台、ID 与本机能力；全局操作记录将设备和 Agent 分列，设备详情省略重复设备列。
- 统一筛选框箭头与间距，优化窄屏布局，清理旧能力编辑控件及未使用样式。
- 新设备使用 12 位随机 Base64URL ID，生成时检查重复；既有设备 ID、凭据、连接策略和历史记录保持有效。

## 0.4.1 — 开发候选（2026-11-13）

- App 与浏览器扩展通过管理台确认和一次性 PKCE 授权码绑定设备，客户端自动保存设备凭据。
- 实例管理员独立登录、创建用户并查看全局设备统计；普通账户继续管理自己的设备和 Agent 连接。
- Agent 连接支持指定设备或包含新设备的全部设备、逐设备能力、可选到期时间、权限预览和独立密钥轮换。
- 管理台新增设备详情、可筛选分页的操作记录；扩展设置合并到弹窗，Mac 设置改用原生控件。
- 桌面与浏览器动作默认等待 2 秒后观察，支持 `wait_after_ms=0–10000`；取消或关闭会话可中断等待。
- 修复桌面状态过期导致的假离线、动作后已选窗口丢失、权限变更后设备详情使用旧策略，以及编辑连接意外延长到期时刻。
- 修复扩展弹窗的任务状态更新，减少管理台重复请求，为活动会话查询增加索引，并清理旧设置页及未使用代码。
- 分发包由根版本统一生成；macOS 候选包使用 ad hoc 签名、未公证，浏览器 ZIP 供开发者加载或上传商店。

## 0.3.0 — 开发候选

### 架构

- Server、桌面运行时、扩展与管理台统一为 strict TypeScript，共享 `abridge/1` 协议和消息 schema。
- Server 使用 Fastify 5、官方 MCP SDK v2 与 Node 内置 SQLite；管理台采用预构建 Preact 11 静态产物。
- CLI 默认启动 Server，提供 `--web` 管理台入口、数据目录及反向代理来源配置。
- Swift 壳调用独立 Node 运行时；桌面按需加载官方 Cua Node SDK，Server 分发剥离桌面依赖。
- 软件版本改由根 `package.json` 单源生成各分发产物版本。

### 执行

- App 与浏览器扩展分别注册设备并直接连接 Server，独立授权、暂停与清理任务资源。
- 浏览器导航固定返回新观察；动作默认附带后观察，观察失败与动作效果分别返回。
- Shell 默认最多等待 15 秒，短命令直接返回结果；长任务可继续等待、取消及按偏移分页读取。
- 区分闲置到期、停止、连接中断和服务重启，结果未知的动作不自动重放。
- Host/Origin 使用明确白名单；首次管理账户的浏览器配置仅限回环空数据库与一次性令牌。

本版本的构建、协议与打包检查不代表实际 App 系统权限、桌面输入或既有线上服务已完成替换验收。
