# 变更记录

此文件记录产品行为变更；部署日志、私人任务结果与模型验收流水不作为版本记录。

## 0.3.0 — 开发候选

### 架构

- Server、桌面运行时、扩展与管理台统一为 strict TypeScript，共享 `abridge/1` 协议和消息 schema。
- Server 使用 Fastify 5、官方 MCP SDK v2 与 Node 内置 SQLite；管理台采用预构建 Preact 11 静态产物。
- CLI 默认启动 Server，提供 `--web` 管理台入口、数据目录及反向代理来源配置。
- Swift 壳调用独立 Node 运行时；桌面按需加载官方 Cua Node SDK，Server 分发剥离桌面依赖。
- 软件版本改由根 `package.json` 单源生成各分发产物版本。

### 执行

- App 与浏览器扩展分别注册设备并直接连接 Server，独立授权、暂停与清理任务资源。
- 浏览器导航固定返回新观察；动作默认附带后观察，观察失败与动作效果分别返回。
- Shell 默认最多等待 15 秒，短命令直接返回结果；长任务可继续等待、取消及按偏移分页读取。
- 区分闲置到期、停止、连接中断和服务重启，结果未知的动作不自动重放。
- Host/Origin 使用明确白名单；首次管理账户的浏览器配置仅限回环空数据库与一次性令牌。

本版本的构建、协议与打包检查不代表实际 App 系统权限、桌面输入或既有线上服务已完成替换验收。
