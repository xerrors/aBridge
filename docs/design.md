# 设计与资产

## 品牌

采用桥接标记与双色 `aBridge` 字标。

| 用途                   | 颜色      |
| ---------------------- | --------- |
| Bridge / 品牌 / 主操作 | `#0066DD` |
| a                      | `#4D94E8` |
| 悬停                   | `#0058C2` |
| 浅蓝背景               | `#EDF4FF` |

品牌、按钮及在线状态不使用绿色。状态栏使用单色模板图，随 macOS 明暗主题呈现。字标使用 Helvetica Bold，保留双层 `a` 并将右下脚修为平直竖向收尾，导出为矢量路径，不依赖接收端安装字体。

## 资源单源

`docs/assets/brand/bridge.svg` 是桥标矢量源；字标由 `tools/brand-wordmark.swift` 的 Helvetica-Bold 定义生成 `docs/assets/brand/wordmark.svg`。统一导出以下派生资源：

| 使用位置                   | 资源目录                      |
| -------------------------- | ----------------------------- |
| App 图标、状态栏模板和字标 | `apps/desktop/native/assets/` |
| 浏览器扩展图标             | `apps/browser/public/icons/`  |
| 管理台 SVG                 | `apps/web/public/`            |

在 macOS 使用 `npm run icons` 从矢量源导出；导出需要 Xcode Command Line Tools、librsvg 的 `rsvg-convert` 与系统 `iconutil`。正常产品构建直接使用已导出的资源生成分发产物。状态栏图标采用单色 template 图，字标使用矢量路径，避免依赖接收端安装字体。

## 界面

扩展点击图标打开小面板，绑定、设备信息和诊断在同一弹窗内展开，不另开设置页。App 状态栏提供常用控制，设置窗按连接、本机能力和系统权限分组，运行诊断默认折叠。管理台围绕设备、Agent 连接和记录组织。连接权限按设备编辑，设备范围明确区分指定设备与包含新设备的全部设备；密钥轮换与权限编辑分开。

App 设置使用原生控件和随系统明暗变化的分组表面；系统权限只显示 App 的实际授权，驱动执行权限、Node 和 Cua Driver 状态放在运行诊断中。诊断展开或收起时窗口随内容调整高度。

设备列表整行可进入独立详情页，停止操作保留单独按钮；详情页顶部集中显示名称、状态、类型、平台、ID 和只读本机能力，名称通过编辑入口修改，停止与解绑保持独立。全局操作记录按设备、Agent 连接及具体操作类型组合筛选，设备详情固定当前设备范围；记录在服务端筛选后分页，设备与 Agent 分列；设备详情省略重复的设备列，保留已解绑设备和已撤销连接的历史。

用布局、分组和层级解释结构。只保留必要的状态、字段、动作和错误，不增加描述段落或重复提示。保留键盘焦点、必要的加载和失败状态；连接未知时不能保留“已连接”的旧状态。
