# 设计与资产

## 品牌

采用桥接标记与双色 `aBridge` 字标。

| 用途                     | 颜色      |
| ------------------------ | --------- |
| Bridge / 品牌 / 在线状态 | `#0066DD` |
| a                        | `#4D94E8` |
| 悬停                     | `#0058C2` |
| 浅蓝背景                 | `#EDF4FF` |

品牌和在线状态使用蓝色。macOS 状态栏使用随系统明暗主题变化的单色模板图。字标以 Helvetica Bold 为基础，保留双层 `a`，将右下脚修成平直的竖向收尾，再导出成矢量路径。

管理台采用中性表面与黑色主操作：画布 `#FAFAFA`、表面 `#FFFFFF`、正文及主按钮 `#171717`、次级文字 `#666666`、边框 `#E5E5E5`。蓝色保留给品牌、在线与可用状态、链接和键盘焦点。应用控件圆角为 6px，列表表面为 8px，弹窗为 12px；以 1px 边框分组，阴影只用于浮层。管理台自托管 Geist Sans 的 400、500、600 字重，中文使用系统字体，代码使用系统等宽字体；不依赖外部字体服务。

## 独立管理员后台

`/admin` 以 [Materio Free](https://github.com/themeselection/materio-mui-nextjs-admin-template-free/tree/3f28aff6111823a24357bbe87fcef312b399d20c) 为设计参考。登录沿用左侧插画、右侧表单，桌面工作区使用 260px 左侧导航、紫色渐变选中项和右上角退出入口。指标卡使用带浅紫底的图标，列表使用浅色表头，单图标动作采用圆形按钮并提供可访问名称。后台各模块共享这些样式，页面按实际管理任务选择字段和操作。

## 资源单源

`docs/assets/brand/bridge.svg` 是桥标矢量源；字标由 `tools/brand-wordmark.swift` 的 Helvetica-Bold 定义生成 `docs/assets/brand/wordmark.svg`。统一导出以下派生资源：

| 使用位置                   | 资源目录                      |
| -------------------------- | ----------------------------- |
| App 图标、状态栏模板和字标 | `apps/desktop/native/assets/` |
| Android 首页桥标           | `apps/android/ui/public/`     |
| Android 桌面图标           | `apps/android/src/main/res/`  |
| 浏览器扩展图标             | `apps/browser/public/icons/`  |
| 管理台 SVG                 | `apps/web/public/`            |

在 macOS 使用 `npm run icons` 从矢量源导出；导出需要 Xcode Command Line Tools、librsvg 的 `rsvg-convert` 与系统 `iconutil`。正常产品构建直接使用已导出的资源生成分发产物。状态栏图标采用单色 template 图，字标使用矢量路径，避免依赖接收端安装字体。

## 界面

扩展工具栏弹窗显示当前浏览器、连接状态和暂停、恢复、停止任务等即时操作。连接标签页承担绑定、改名、解除绑定和诊断，按绑定状态显示相应内容；Chrome 权限提示切走焦点时保留绑定表单。App 状态栏提供常用控制，设置窗按连接、本机能力和系统权限分组，运行诊断默认折叠。管理台采用固定左侧导航与右侧工作区，围绕概览、设备、Agent 连接和操作记录组织；主要面向桌面宽度，不维护超窄屏专用布局。概览并列展示设备卡片和 Agent 连接，未完成接入时只显示一个下一步入口。连接权限按设备编辑，设备范围明确区分指定设备与包含新设备的全部设备；密钥轮换与权限编辑分开。

App 设置使用原生控件和随系统明暗变化的分组表面。「系统权限」显示当前 App 的授权情况，「运行诊断」显示驱动及运行时状态。打开或收起诊断时，窗口随内容调整高度。

Android 客户端使用随 APK 打包的 Tamagui 界面。设备连接状态和 Agent 访问状态分别显示，绑定后默认关闭 Agent 访问。首页显示当前可用的本机能力，能力选择保留在「能力设置」中。文件能力依赖系统选择器授予的目录读写权限。

设备列表采用卡片网格，整张卡片进入独立详情页，停止操作保留单独按钮，不因当前没有在途操作而禁用。详情页分为概况、操作记录与设置；概况展示名称、状态、类型、平台、ID、只读本机能力和可访问此设备的 Agent，设置集中改名、重新生成凭据与解绑。停止与解绑保持独立。全局操作记录按设备、Agent 连接及具体操作类型组合筛选，设备详情固定当前设备范围；记录在服务端筛选后分页，设备与 Agent 分列；设备详情省略重复的设备列，保留已解绑设备和已撤销连接的历史。

用分组、对齐和间距说明界面结构。文案说明当前状态、可用动作和错误后的下一步。连接状态未知时显示「状态未知」，并为键盘操作提供清晰的焦点反馈。

管理台设备列表支持按名称、平台或 ID 搜索，并按类型与状态筛选；空列表直接提供电脑和浏览器绑定入口。停止、复制和表单提交显示执行反馈，处理中禁止重复提交；复制失败保留可选中的原文。解除绑定和撤销连接须在确认窗中说明目标与后果。更多操作支持点外部或按 Escape 收起；弹窗关闭后返回触发控件。

## 接入流程

添加设备页按 macOS、Windows、Linux、Android 和浏览器扩展展示入口。macOS、Windows 和扩展可选择浏览器授权或设备凭证，Linux 和 Android 直接生成设备凭证。浏览器授权后到设备列表确认状态。生成凭证后，页面按返回的设备 ID 跟踪连接状态，仍保留凭证供用户保存。

Agent 连接采用“设置访问权限 → 配置 Agent”两步流程。创建后直接显示一次性 Key、MCP 地址及可复制 JSON，确认保存后进入连接详情。详情以深链接提供设备权限、接入配置、操作记录和设置；记录固定当前连接范围。权限选择明确区分指定设备与包含新设备的全部设备，切换范围分别保留选择。

一次性凭据未确认保存时，站内导航、浏览器返回与刷新均提供离开提示；账户退出或身份切换仍立即清空旧凭据。创建成功后的列表刷新失败不清除已返回的凭据。连接、设备和记录的空状态给出具体下一步；离线、暂停及状态未知不能显示为就绪。

接入流程用居中的单列布局和横向进度。详情页用行列展示权限、能力和基础信息，在改变权限的操作旁说明影响。

## 图标

通用界面图标使用 `lucide-preact` 的具名组件。操作图标为 16px，导航为 18px，设备为 22–24px，线宽统一为 1.75。给只显示图标的操作加上可访问名称。

平台图标源文件放在 `docs/assets/brand/platforms/`，构建复制到管理台静态资源。Chrome、Linux、Windows、Android 使用 SVG Logos（`@iconify-json/logos` 1.2.20）；macOS 使用 Finder 蓝白笑脸 SVG 图标（用户提供），不使用通用 Apple 标识。保留原始配色和比例，只根据明确的平台标识选择品牌；未知平台及仅上报“Browser extension”的浏览器设备使用通用图标。添加设备页中的 Chrome 表示扩展安装入口，不表示所有浏览器设备都是 Chrome。

表单、搜索与筛选控件统一为 40px 高，6px 圆角；选择框使用公共 Select 组件，保留原生下拉和键盘操作，以 Lucide ChevronDown 统一箭头，距右侧 12px、垂直居中。折叠区也使用同一箭头，通过朝向表达开合。弹窗内表单提交期间，取消、关闭与 Escape 同步禁用；记录翻页保留分页控件及键盘焦点，刷新与重试状态覆盖记录请求。
